# Ibrahim Hassan Abdelstar - Interactive Personal Portfolio

A dark-mode personal portfolio built with HTML5, CSS3, Vanilla JavaScript, GSAP, and Three.js based strictly on the professional CV of **Ibrahim Hassan Abdelstar**.

## Features

- **Interactive 3D Background**: Responsive Three.js particle system reacting to cursor movement.
- **Cinematic Entrance & Scroll Animations**: Built with GSAP & ScrollTrigger.
- **Project Detail Modal**: Dynamic modal presentation for key project case studies.
- **Custom Hardware Cursor**: Smooth dual-ring cursor with expanding states over hover elements.
- **Strict Data Integrity**: Fully representative of the CV with zero fabricated metrics or experience.

## Getting Started

1. Clone or download the repository.
2. Open `index.html` directly in any modern browser (or serve via Live Server / local static server).
3. No build tools or Node package installations are required.
